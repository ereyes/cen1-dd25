# Galerie des travaux étudiants

Ce dépôt contient une galerie HTML simple permettant de présenter les travaux réalisés par les étudiant·es dans le cadre du cours Web graphique et design de données.

La page propose une interface inspirée de Material Design. Chaque projet est présenté sous forme de carte avec une capture d’écran, le titre du travail, le nom de l’étudiant·e.
